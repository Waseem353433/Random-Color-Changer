# Random-Color-Changer
🎨 Background Color Changer
📌 Project Description

This is a simple Background Color Changer Application built using HTML, CSS, and JavaScript.
The app changes the background color of the webpage randomly each time the user clicks a button.

🚀 Features
🎨 Random background color generation
🖱️ Button click to change color
⚡ Instant UI update using DOM manipulation
🌈 Unlimited color variations
🛠️ Technologies Used
HTML – Structure of the webpage
CSS – Styling
JavaScript – Logic and DOM manipulation
